Prototype technique

Un engin sur un chantier

Conduisez l'engin jusqu'à la zone d'arrivée en évitant les cônes et sans tomber en panne de carburant. Le score récompense le carburant restant et pénalise chaque cône touché.

Objectif

  • Atteindre le disque d'arrivée à {{ target?.x }}, {{ target?.z }} m.
  • Éviter les {{ coneCount }} cônes posés sur le trajet.
  • Gérer les {{ fuelCapacity }} unités de carburant ({{ consumptionPerMeter.toFixed(1).replace('.', ',') }} par mètre parcouru).

Commandes

  • ZQSD ou WASD : conduire
  • ↑←↓→ : alternative
  • R : recommencer · Échap : accueil
  • I : inspecteur Babylon

Score

{{ scoring?.base ?? 0 }} points de base

− {{ scoring?.penaltyPerConeHit ?? 0 }} par cône touché

+ {{ scoring?.bonusPerFuelUnit ?? 0 }} par unité de carburant restante

Démarrer la partie

La partie se joue au clavier, en plein écran.
